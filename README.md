# IMXP · Business Readiness — Mini Deck

A short (7-slide) concept deck for IMXP's **Business Readiness** feature: a business
"avatar" an owner builds once and shares selectively with advisors and lenders.

Built from Mitch's product screenshot (My Profile → Business Readiness). Sections shown:
Basic Info · Business Story · Team & Ownership · Financial Snapshot · Capital & Debt ·
Connected Accounts (coming soon).

## View
Open `index.html`, or the GitHub Pages URL once published.

Cover → The gap → The idea → How it works (6 sections) → Built for control → What's next → Close.

(Archivo / Inter, dark stage, accent palette).
